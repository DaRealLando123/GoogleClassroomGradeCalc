## Contributions mostly written by AI are only acceptable if:
1. You understand the code that was written and can provide a summary (written by yourself) of what the code technically does.
2. You’ve rigorously tested and proven the extension works well with little to no bugs.
3. The code runs well and is optimized and reviewed.
4. The code follows all the contributing guidelines. (No random whitespaces, irregular function names and comments, etc.)

## Contributing Guidelines are as follows:

Code typically is written with this syntax in mind:

var x = “a”;

function run(arg1){
    console.log(`The input was ${arg1}.`);
    switch(x){
        case “a”:
            console.log(“case was A”)
            break
        case “b”:
            console.log(“case was B”)
            break
    }
    return;
}
